# ОкнаБел — установка пластиковых окон в Белорецке

Одностраничный лендинг для компании по установке пластиковых окон в г. Белорецк.

## 🚀 Деплой на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `oknabel`).
2. Загрузите файлы: `index.html`, `styles.css`, `script.js`, `README.md`.
3. Перейдите в **Settings → Pages**.
4. В разделе **Source** выберите ветку `main` (или `master`) и папку `/ (root)`.
5. Нажмите **Save**. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
